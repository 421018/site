## Check instead of trust {#start}

The protocol is designed so its results can be checked. The site follows the same criterion: every important statement about the protocol and the network has a public source where it can be verified.

Some sources are maintained by the protocol's contributors; others, such as the explorers, are offered by independent providers.

## The project's channels {#channels}

These are the project's only official channels. If a channel does not appear here, it is not official, even if it uses the name 42 Chain.

| Channel | What it is for | Address |
|---|---|---|
| Website | What the protocol is, how it works and how to implement it | [site domain] |
| Documentation | Step-by-step guides and technical reference | [documentation domain] |
| Repository | Source code, technical questions, bug reports and contributions | [repository] |
| Security email | Private reports of vulnerabilities in the code | [security email] |

RPC providers and explorers are independent and have their own domains. Their addresses are in the [provider directory](docs:/get-started/connect#providers).

:::note[Before trusting a message]
No channel of the project will ask you for your recovery phrase or your private keys. Verify any announcement or link against this list.
:::
